# initial

This directory deliberately starts empty. To build the multi-project layout from scratch, generate the three module starters from the forge per the guide chapters:

- `GET /create/web_plugin/example.shared` -> `shared-core/`
- `GET /create/web/example.customer` -> `webapp-customer/`
- `GET /create/web/example.admin`    -> `webapp-admin/`

Then create the root `settings.gradle` and `build.gradle` shown in the guide. The `complete/` tree alongside this directory is the result.
